## 🚀 Featured Project

### 🔐 Identity Audit

Identity & privilege auditing platform for **Active Directory** and **Microsoft Entra ID**,
aligned with **CIS Controls 5 and 6**.

The project includes:

- identity, group, role and privilege collection;
- Active Directory auditing through LDAPS;
- Microsoft Entra ID simulated collection;
- CIS-oriented compliance evaluation;
- JWT authentication and RBAC;
- audit logging and traceability;
- CSV and PDF reporting;
- Linux deployment with Nginx, HTTPS and systemd.

**Tech stack:**  
`C#` · `ASP.NET Core` · `React` · `TypeScript` · `PostgreSQL` · `Entity Framework Core` · `JWT` · `RBAC` · `Linux` · `Nginx`
